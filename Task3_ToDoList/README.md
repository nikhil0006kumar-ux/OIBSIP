# Task 3 – To‑Do List ✅  
## Batch: AICTE OIB-SIP September P1  

## 🎯 Objective  
To build a To‑Do List web application that allows users to add, manage, and delete tasks effectively.  

## 📝 Steps Performed  
- **HTML (index.html):**  
  - Created input field for entering tasks.  
  - Added a container to display the list of tasks.  

- **CSS (style.css):**  
  - Styled the app with a clean and responsive design.  
  - Used spacing, colors, and alignment for better readability.  

- **JavaScript (script.js):**  
  - Implemented functionality to add new tasks dynamically.  
  - Added delete button to remove tasks.  
  - Implemented mark‑complete feature to strike through finished tasks.  
  - Used DOM manipulation and event listeners for interactivity.  

## 🛠 Tools Used  
- HTML  
- CSS  
- JavaScript  

## 📊 Outcome  
A responsive To‑Do List app that helps users manage their daily tasks.  
This project demonstrates DOM manipulation, event handling, and dynamic updates in JavaScript.
