# Task 2 – Tribute Page 🌟  
## Batch: AICTE OIB-SIP September P1  

## 🎯 Objective  
To design a tribute page dedicated to a famous personality, showcasing their life, achievements, and contributions.  

## 📝 Steps Performed  
- **HTML (index.html):**  
  - Structured the page with headings, paragraphs, and sections.  
  - Added an image of the personality with proper alt text.  
  - Included biography and achievements in a clean layout.  

- **CSS (style.css):**  
  - Styled the page with fonts, colors, and spacing for readability.  
  - Used responsive design principles to ensure compatibility across devices.  
  - Added alignment and background styling for a professional look.  

## 🛠 Tools Used  
- HTML  
- CSS  

## 📊 Outcome  
A well‑designed tribute page that highlights the personality’s life and achievements in a visually appealing and structured format.  
This project demonstrates content structuring, semantic HTML usage, and CSS styling.
