# Task 1 – Calculator 🧮
## Batch: AICTE OIB-SIP September P1

## 🎯 Objective
To build a functional calculator using HTML, CSS, and JavaScript that performs basic arithmetic operations.

## 📝 Steps Performed
- **HTML (index.html):**
  - Created calculator layout with buttons for digits (0–9), operators (+, -, ×, ÷), and special keys (C, =).
  - Added a display section to show input and results.

- **CSS (style.css):**
  - Styled calculator with a clean and responsive design.
  - Used grid/flex layout for proper button alignment.
  - Added hover effects for better user experience.

- **JavaScript (script.js):**
  - Implemented event listeners for button clicks.
  - Handled operations: addition, subtraction, multiplication, division.
  - Added functionality for clear/reset button.
  - Displayed results dynamically in the calculator screen.

## 🛠 Tools Used
- HTML  
- CSS  
- JavaScript  

## 📊 Outcome
A responsive calculator that allows users to perform basic arithmetic operations with a simple and intuitive interface.  
This project demonstrates DOM manipulation, event handling, and styling in web development.
