# Task 4 – Login Authentication 🔐  
## Batch: AICTE OIB-SIP September P1  

## 🎯 Objective  
To build a login authentication system with proper validation using HTML, CSS, and JavaScript.  

## 📝 Steps Performed  
- **HTML (index.html):**  
  - Created a login form with input fields for username/email and password.  
  - Added a submit button and placeholders for error messages.  

- **CSS (style.css):**  
  - Styled the login form with a clean and responsive design.  
  - Used alignment, spacing, and background styling for better UI.  

- **JavaScript (script.js):**  
  - Implemented validation checks for empty fields.  
  - Added conditions to verify username and password format.  
  - Displayed error messages dynamically for invalid input.  
  - Ensured proper feedback when login credentials are correct or incorrect.  

## 🛠 Tools Used  
- HTML  
- CSS  
- JavaScript  

## 📊 Outcome  
A secure login form that validates user credentials and provides error messages for incorrect input.  
This project demonstrates form validation, DOM manipulation, and user interaction handling in JavaScript.
